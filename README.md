## What it does

`main.py` (Python 3 stdlib only) writes a single line to `entry.txt` in the
output directory given by `MAKEFUN_OUTPUT_DIR` (fallback `/output`): a funny
name for a band made of robots — The Backstreet Bots — plus a few words on
their hit song. The line is under 200 characters, deterministic, and written
the same way on every run.
